## Ecosystem Metaphors

```yaml
!CLAUSE: !PME_READY
ID: Narrative.EcosystemMetaphor.1.0.0
Summary: The living-tree metaphor for the Toolbox hierarchy
TargetPhase: Gleam
DeclaredBy: Glee-fully FoundRy
```

The Glee-fully suite is organized like a living tree:

- 🧰 **Toolbox (Trunk)** — the command center and concierge; routes, does not execute
- 🪚 **Tools (Branches)** — major life domains (Careers, Treasures, Food, Travel, Life, Wellness, Identity)
- 🔩 **Tool-ettes (Twigs)** — specialized GPTs that users interact with most directly
- ⚙️ **Functions (Leaves)** — embedded logic supporting Tool-ettes (export, tag, format)
- 🧧 **Function-ettes (Falling Leaves)** — atomic actions (text cleaning, metadata tagging)
